# MT-33 — Workflow Pause, Resume & Cancel

## 1. Context
Add workflow control operations: pause execution, resume from pause point, and cancel running workflows.

## 2. Prerequisites
- MT-30 complete (parallel executor)
- MT-32 complete (WebSocket for status)

## 3. Goal
- Pause running workflow (stops new stages, completes current)
- Resume paused workflow (continues from where it stopped)
- Cancel workflow (stops all stages immediately)
- State machine (running → paused → running, running → cancelled)
- API endpoints for control operations

## 4. Implementation

### 4.1 Add control signals

```python
# backend/app/services/execution/parallel_executor.py

class ParallelExecutor:
    def __init__(self, db: AsyncSession):
        # ... existing ...
        self.control_signals: Dict[uuid.UUID, str] = {}  # execution_id -> signal
    
    def pause(self, execution_id: uuid.UUID):
        self.control_signals[execution_id] = "pause"
    
    def resume(self, execution_id: uuid.UUID):
        if execution_id in self.control_signals:
            del self.control_signals[execution_id]
    
    def cancel(self, execution_id: uuid.UUID):
        self.control_signals[execution_id] = "cancel"
    
    async def _check_control_signal(self, execution_id: uuid.UUID):
        signal = self.control_signals.get(execution_id)
        
        if signal == "pause":
            # Wait until resumed
            while self.control_signals.get(execution_id) == "pause":
                await asyncio.sleep(0.5)
        
        if signal == "cancel":
            raise CancelledException("Workflow cancelled by user")
```

### 4.2 Control API endpoints

```python
# backend/app/api/execution.py

@router.post("/executions/{execution_id}/pause")
async def pause_execution(execution_id: uuid.UUID):
    # Set pause signal
    engine.parallel_executor.pause(execution_id)
    return {"message": "Paused"}

@router.post("/executions/{execution_id}/resume")
async def resume_execution(execution_id: uuid.UUID):
    engine.parallel_executor.resume(execution_id)
    return {"message": "Resumed"}

@router.post("/executions/{execution_id}/cancel")
async def cancel_execution(execution_id: uuid.UUID):
    engine.parallel_executor.cancel(execution_id)
    return {"message": "Cancelled"}
```

### 4.3 Frontend controls

```tsx
// frontend/src/components/ExecutionControls.tsx
export const ExecutionControls = ({ executionId, status }) => {
  const handlePause = async () => {
    await fetch(`/api/executions/${executionId}/pause`, { method: 'POST' });
  };
  
  const handleResume = async () => {
    await fetch(`/api/executions/${executionId}/resume`, { method: 'POST' });
  };
  
  const handleCancel = async () => {
    if (confirm('Cancel execution?')) {
      await fetch(`/api/executions/${executionId}/cancel`, { method: 'POST' });
    }
  };
  
  return (
    <div>
      {status === 'running' && <button onClick={handlePause}>⏸ Pause</button>}
      {status === 'paused' && <button onClick={handleResume}>▶ Resume</button>}
      {(status === 'running' || status === 'paused') && 
        <button onClick={handleCancel}>⏹ Cancel</button>}
    </div>
  );
};
```
