# MT-03 — Alembic Setup & Initial Migration

## 1. Context
With ORM models defined (MT-02), we need a migration system to create and evolve the database schema. Alembic is the standard migration tool for SQLAlchemy. This MT sets up Alembic configuration, the `env.py` that auto-detects models, and runs the first migration to create `workflows`, `stages`, and `stage_dependencies` tables.

## 2. Prerequisites
| What | Why |
|------|-----|
| **MT-02 complete** | ORM models exist in `backend/app/models/` |
| **PostgreSQL running** | Migration needs a live database |
| **Database created** | `ai_orchestrator` database must exist in PostgreSQL |

**Pre-flight DB creation (if not done):**
```powershell
# Using Docker Compose postgres from MT-00:
docker-compose up -d postgres
# Or manually:
# createdb -U orchestrator ai_orchestrator
```

## 3. Goal
After this MT:
- `backend/alembic.ini` is configured with the sync database URL.
- `backend/alembic/env.py` auto-imports all models and supports async migrations.
- The first migration file exists in `backend/alembic/versions/`.
- Running `alembic upgrade head` creates all three tables in PostgreSQL.
- The tables can be verified via SQL.

### 4.2 `backend/alembic/env.py`

**File: `backend/alembic/env.py`**

```python
"""
Alembic environment configuration.
Auto-detects all SQLAlchemy models via Base.metadata.
Supports both online (sync) and offline migration modes.
"""

import sys
from pathlib import Path
from logging.config import fileConfig

from sqlalchemy import engine_from_config, pool
from alembic import context

# Add the repo root to sys.path so 'backend.app.models' can be imported
sys.path.insert(0, str(Path(__file__).resolve().parents[2]))

from backend.app.config import settings
from backend.app.database import Base

# Import all models so Base.metadata is populated
from backend.app.models import Workflow, Stage, StageDependency  # noqa: F401

# Alembic Config object
config = context.config

# Override sqlalchemy.url from our settings (uses SYNC url for Alembic)
config.set_main_option("sqlalchemy.url", settings.DATABASE_URL_SYNC)

# Setup logging
if config.config_file_name is not None:
    fileConfig(config.config_file_name)

# Target metadata for autogenerate
target_metadata = Base.metadata


def run_migrations_offline() -> None:
    """Run migrations in 'offline' mode — generates SQL without DB connection."""
    url = config.get_main_option("sqlalchemy.url")
    context.configure(
        url=url,
        target_metadata=target_metadata,
        literal_binds=True,
        dialect_opts={"paramstyle": "named"},
    )
    with context.begin_transaction():
        context.run_migrations()


def run_migrations_online() -> None:
    """Run migrations in 'online' mode — connects to DB and applies changes."""
    connectable = engine_from_config(
        config.get_section(config.config_ini_section, {}),
        prefix="sqlalchemy.",
        poolclass=pool.NullPool,
    )
    with connectable.connect() as connection:
        context.configure(
            connection=connection,
            target_metadata=target_metadata,
        )
        with context.begin_transaction():
            context.run_migrations()


if context.is_offline_mode():
    run_migrations_offline()
else:
    run_migrations_online()
```

### 4.4 Generate & run the initial migration

**PowerShell commands (run from `backend/` directory):**

```powershell
# Navigate to backend (alembic.ini is here)
cd backend

# Generate the initial migration
python -m alembic revision --autogenerate -m "initial_tables_workflows_stages_dependencies"

# Apply the migration
python -m alembic upgrade head

# Verify tables exist
python -c "
import psycopg2
conn = psycopg2.connect('postgresql://orchestrator:orchestrator_dev@localhost:5432/ai_orchestrator')
cur = conn.cursor()
cur.execute(\"\"\"SELECT table_name FROM information_schema.tables WHERE table_schema = 'public' ORDER BY table_name\"\"\")
tables = [row[0] for row in cur.fetchall()]
print('Tables:', tables)
assert 'workflows' in tables, 'workflows table missing'
assert 'stages' in tables, 'stages table missing'
assert 'stage_dependencies' in tables, 'stage_dependencies table missing'
print('PASS')
conn.close()
"

# Go back to repo root
cd ..
```
